# Automated Cloud Credit Risk Engine

**Project Overview:**
Built an end-to-end data pipeline to evaluate 10,000 loan applications, enforce risk logic (excluding applicants aged 59+), and generate prime sales leads.

* **Cloud Database:** Microsoft Azure SQL Database.
* **Data Engineering:** Wrote custom multi-variable T-SQL logic in VS Code to calculate risk tiers, income-to-loan ratios, and dynamically approve capital limits.
* **Business Intelligence:** Connected the live Azure SQL view to Power BI to visualize 51M in total approved capital and filter an actionable lead list for the sales team.
